# 공개 및 포트폴리오 관리

사용자는 2026-09-07 코드·문서 중심 공개 전환을 승인했다. 대회 데이터 이용 제한은 그대로 적용한다.

## 공개 대상
- 직접 작성한 코드, 권리와 고지 의무를 확인한 외부 코드
- 일반적인 설계·검증 방법, 실행 안내, 출처 및 제한사항
- 공개 가능성을 확인한 집계 성능과 사실에 근거한 개발 기록

## 제외 대상
- 제공 영상 및 파생/오버레이 이미지, 원본 라벨·sites.json·개소 좌표
- 학습/사전학습 가중치, 데이터 캐시, 예측 원문, 제출 ZIP
- 참여키·HF 토큰·환경파일·서버 응답 원문·노트북 실행 출력
- 실제 로컬 경로 설정은 configs/local.json에 보관

## 공개 전 절차
1. git diff와 전체 Git 이력 검사 스크립트로 파일·비밀정보·노트북 출력을 확인한다.
2. 새 코드·문서의 출처와 권리, 이미지/표에 실제 데이터가 포함되는지 사람이 함께 검토한다.
3. 실험 결과를 기록할 때 검증 방법·commit과 한계를 명시하고 미측정 수치는 쓰지 않는다.
4. 검사를 통과한 코드·문서 변경만 commit/push한다. 로컬 pre-push 훅이 검사한다. GitHub workflow 권한이 없어 CI는 등록하지 않았다. 새 clone에서는 git config core.hooksPath .githooks를 실행해야 훅이 활성화된다.

자동 검사는 보조 수단이며 확장자가 바뀐 데이터나 모든 비밀정보를 탐지하지는 못한다.
대회 제출과 공개 저장소는 별개다. 제출용 LICENSE/NOTICE 의무는 해당 자산 사용 시 별도로 충족한다.

## 초기 공개 검토
기존 2개 커밋은 프로젝트 문서·경로 예시·빈 기록표만 포함했다. 원본 영상·좌표·가중치·키가 없음을 확인한다.
과거 설정 예시에 로컬 사용자명과 경로가 남아 있으나 인증정보나 대회 데이터는 아니다. 현재 예시는 범용 경로로 변경했다.

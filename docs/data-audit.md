# 읽기 전용 데이터 점검

`scripts/audit_data.py`는 configs/local.json의 train_dir 또는 --train-dir 경로를 읽는다. 베이스라인 모델은 불러오지 않는다. 제공 predict.py는 10밴드 TIFF와 지리좌표를 사용하므로 현재 학습 데이터용 로더로 직접 사용할 수 없다.

## 검사 범위

- 창 이름 ls_scene_<숫자>_w<숫자>에서 scene을 추출한다. scene 집계이며 검증 분할 생성은 아니다.
- bands/YYYYMMDD.npy, images/YYYYMMDD.png, labels/YYYYMMDD.json의 연결 및 날짜 형식.
- NPY는 allow_pickle=False, (256,256,4), uint16 확인. PNG는 크기·형식·무결성 및 디코딩 확인.
- Red>0 & NIR>0 유효 화소 비율. 값 10000 초과도 집계하되 클리핑·오프셋 재보정은 하지 않는다.
- site_id 중복·미등록, 라벨 누락, ignore, visible 값 확인. visible 정수 0만 음성이며 누락·ignore·중복은 음성 처리하지 않는다.
- 픽셀 좌표 MultiPolygon의 유한성, 0~256 범위, 링 구조 및 도형 유효성 검사. 첫 점이 반복되지 않은 링은 라이브러리가 메모리에서 닫으며 원본은 수정하지 않는다.
- 양성 중 유효 폴리곤의 연속 면적 10px² 이상/미만 집계. 부적합 폴리곤은 면적 집계에서 제외한다. 자동 도형 복구는 하지 않는다.

보고서에는 경로, scene/site 식별자, 날짜 목록, 좌표, 이미지가 없고 집계만 포함한다. 기본 실행은 파일을 쓰지 않는다. 오류는 종료 코드 1, 시작 불가 설정 오류는 2, 오류 없는 완료는 0이다. 경고만으로 실패하지 않는다.

전체 NPY 형식 검사와 PNG 읽기가 통과했다. 정답 폴리곤 3건 때문에 전체 상태는 fail이다. 위 면적 집계는 유효 도형만 대상으로 하며 공식 형상 평가 대상 수를 확정한 결과가 아니다. 해당 도형 처리 정책은 평가 구현 전에 대회 기준과 맞춰 확인해야 한다.

양성·음성 수는 라벨 분포이지 학습 가능한 샘플 목록이 아니다. 다른 데이터에서 영상 연결 오류 등이 발견되면 별도 처리가 필요하다. 실제 좌표 정합성의 시각 검수, 중첩 창의 공간 누수 검사, 공식 평가 구현과 성능 측정은 이번 검사에 포함되지 않는다.

## 검증

합성 데이터만 사용한 unittest 5개로 누락/ignore/음성 구분, 중복·미등록 개소, 비정상 visible, 손상 JSON·잘못된 배열, 연속 면적·홀·10px² 경계 및 부적합 도형을 검사한다. 테스트용 임시 영상은 직접 생성한 합성 데이터이며 제공 영상에서 파생하지 않는다.

후속 확인: 부적합 정답 3건은 모두 자기 교차이며, 고정 분할에서는 학습 1건·검증 2건이다. [처리 기준과 검증 분할](validation.md)을 참고한다.

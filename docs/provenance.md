## 데이터 점검 코드 (2026-09-07)

`scripts/audit_data.py`는 실제 train 스키마를 바탕으로 새로 작성했다. 제공 predict.py는 입력 형식 비교만 했으며 코드·가중치를 복사하거나 실행하지 않았다. 베이스라인의 10밴드 TIFF/지리좌표 형식은 train의 4밴드 NPY/픽셀좌표 형식과 다르다.
점검 전용 라이브러리 버전은 requirements-audit.txt에 고정했다. 이번 작업에는 외부 데이터나 사전학습 가중치를 도입하지 않았다.

## NDVI 기준 모델

src/baseline.py는 내부·주변 NDVI 차이라는 일반적인 특징을 사용해 새로 작성했다. 제공 베이스라인의 비교 아이디어를 참고했지만 코드·가중치는 복사하거나 실행하지 않았다. 자체 임계값을 고정 학습 분할에서 적합했으며 파라미터는 Git 제외 로컬 파일에만 저장한다. 추가 외부 데이터·사전학습 가중치는 없다.

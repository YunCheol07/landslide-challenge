# 로컬 평가기

src/evaluation.py에 사용자 제공 규칙 기준 평가를 구현했다. 공식 서버 코드와의 동등성은 아직 검증하지 않았으며 출력에 official_server_parity_verified=false를 명시한다.

## 계산

- 존재 판정: 명시적인 visible 정수 0/1만 평가한다. 누락 라벨과 ignore는 제외한다. CSV의 유효 비어 있지 않은 MultiPolygon은 존재, 빈 필드·[]·행 누락은 부재다.
- 존재 macro-F1: 양성 F1과 음성 F1의 산술평균. 분모 0인 클래스 F1은 0으로 두고 항상 두 클래스를 포함한다. 평가 라벨이 하나도 없으면 실패한다. 단일 클래스·분모 0 처리 관례는 공식 서버와 추가 대조가 필요하다.
- 형상: visible:1인 유효 정답 중 연속 면적 10px² 이상만 대상이다. 각 날짜의 교집합 면적/합집합 면적을 계산하고 (location_id, site_id) 내 날짜 평균 후 개소 평균을 낸다. 미예측은 IoU 0이다. 동일 site_id라도 location_id가 다르면 별개다.
- 정답의 작은 도형은 형상에서만 제외하고 존재 평가에는 유지한다. 거짓 양성은 존재 점수에 반영하며 음성 정답은 형상 대상이 아니다.
- 종합: 0.6 × macro-F1 + 0.4 × 개소별 mIoU.
- 자기 교차 등 미확정 정답 도형이 하나라도 있으면 존재 점수는 계산하되 site_miou와 combined_score는 null이다. 자동 복구는 하지 않는다. 형상 대상이 전혀 없어도 두 값은 null로 둔다.
- --diagnostic은 유효 정답만의 진단용 mIoU를 별도 필드에 추가한다. 이 값으로 종합 점수를 계산하지 않는다.

링 끝점 반복은 생략 가능하며 라이브러리가 메모리에서 닫는다. 홀과 여러 폴리곤을 연속 좌표로 처리한다. 래스터화나 정수 반올림은 하지 않는다. 좌표는 유한한 0~256 범위여야 한다. 잘못된 예측 JSON·도형, 중복 행, 알려지지 않은 키는 실패 처리하며 임의로 음성으로 바꾸지 않는다. 예측 오류 처리는 로컬 입력 검증 정책으로, 서버 동작을 주장하지 않는다.

## 실행

```bash
# 선택한 분할에 해당하는 예측 CSV만 입력
.venv/bin/python scripts/evaluate.py --predictions private/predictions.csv
# 모델 없는 실행 검증: 모든 예측을 부재로 설정, 파일 생성 없음
.venv/bin/python scripts/evaluate.py --empty-predictions --diagnostic
```

기본 분할은 validation이며 --partition train으로 바꿀 수 있다. CSV 열 순서는 location_id,date,site_id,polygons이다. 로컬 location_id는 창 폴더 이름, date는 YYYYMMDD 문자열로 매핑한다. polygons는 MultiPolygon coordinates JSON이며 CSV writer로 적절히 인용해야 한다. 이 로컬 매핑은 실제 서버 입력 어댑터 구현 시 다시 확인한다. null 문자열은 허용하지 않는다. 선택 분할 밖 예측은 오류다. 누락·ignore 슬롯의 예측은 입력 키·형식은 검사하지만 점수에서 제외한다.

기존 로컬 분할과 현재 설정·데이터 전체 해시를 검증한 뒤 평가한다. 데이터는 읽기만 하고 결과는 집계 JSON만 표준 출력에 내보낸다. 오류 메시지에는 좌표·개소 식별자·실제 경로를 포함하지 않는다. 종료 코드 0은 모든 점수 산출, 1은 형상 미확정/형상 대상 없음, 2는 입력 또는 실행 오류다.

## 실제 실행 검증

2026-09-07 고정 검증 데이터에 모든 예측을 부재로 둔 실행에서 양성 58건·음성 27건·누락 제외 6건을 확인했다. 존재 macro-F1은 27/112 = 0.2410714286이다. 정답 도형 2건이 미확정이므로 형상·종합 점수는 null이며 종료 코드 1이다. 유효 정답만의 진단용 mIoU는 0이다. 이것은 평가기 동작 확인이며 학습 모델 성능이나 서버 점수가 아니다. experiments/results.csv에는 모델 실험으로 추가하지 않았다.

전체 테스트 18개 중 평가기 테스트 9개는 완전 일치·미예측·혼동행렬, 개소별 가중 방식, location별 식별, 소수 좌표 IoU·홀, 면적 임계값, 누락·ignore, 자기 교차 차단, CSV 오류 등을 검사한다.

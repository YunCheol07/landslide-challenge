# 고정 scene 검증 분할과 도형 처리 기준

## 분할 명세

configs/split.json에 알고리즘 버전, seed 42, 검증 scene 2개, 목표 검증 비율 0.2를 고정했다. scripts/make_split.py는 scene별 유효 visible 양성/음성 수만 이용한다. 가능한 scene 2개 조합 중 아래 목적값을 최소화한다.

`abs(검증 양성 / 전체 양성 - 0.2) + abs(검증 음성 / 전체 음성 - 0.2)`

동점은 seed와 scene 조합의 SHA-256으로 결정한다. 양쪽 분할에 양성과 음성이 모두 있어야 한다. 모델 예측, Public 점수, 실험 성능은 사용하지 않는다. 동일 scene의 모든 창·개소·날짜는 같은 분할에 들어간다. scene 구분은 제공 폴더 이름을 따르며, 다른 scene 간 실제 공간 중첩은 별도 확인이 필요하다.

로컬 private/scene_split.json에 scene 배정, 입력 파일명·내용 전체를 반영한 SHA-256, 설정, 집계를 저장한다. 좌표·영상·라벨 원문은 저장하지 않는다. private/는 Git에서 제외된다. 공개 설정과 코드로 재현할 수 있으며, 구체적인 배정은 로컬에만 보관한다. 재실행 시 내용·파일 구성·설정·집계가 달라지면 실패하고 기존 파일을 덮어쓰지 않는다. 새 실험을 위해 임의로 분할을 다시 뽑지 않는다.

```bash
.venv/bin/python scripts/make_split.py
.venv/bin/python scripts/make_split.py --check
```

첫 명령은 없으면 생성하고 있으면 검증한다. --check는 기존 분할이 있어야 한다. 원본은 읽기 전용으로 스캔하며 파생 영상·패치 캐시를 만들지 않는다. 출력에는 집계만 포함한다.

## 확정 집계 — 2026-09-07

| 항목 | 학습 | 검증 |
|---|---:|---:|
| scene | 5 | 2 |
| 창 | 13 | 2 |
| 영상 | 318 | 27 |
| 창 내 개소 합계 | 55 | 7 |
| 양성 | 584 | 58 |
| 음성 | 932 | 27 |
| 누락 제외 | 84 | 6 |
| 유효 형상 면적 10px² 이상 | 416 | 54 |
| 유효 형상 면적 10px² 미만 | 167 | 2 |
| 도형 처리 미확정 | 1 | 2 |

한 scene이 전체 라벨 1,601건 중 1,450건(90.57%)을 차지한다. 따라서 scene을 유지한 80:20 분할은 불가능하다. 현재 검증 라벨은 85건(5.31%)이며 대표성에 한계가 있다. 기준 모델 이후에는 scene별 결과와 leave-one-scene-out 검증을 추가해 일반화를 확인해야 한다. 이 보조 검증이 기본 분할을 대체하거나 Public 점수에 맞춰 재선정하는 근거가 되어서는 안 된다.

## 자기 교차 정답 폴리곤 3건

Shapely 2.0.7의 explain_validity를 메모리에서 확인한 결과 3건 모두 Self-intersection이다. 첫 점이 반복되지 않은 열린 링과는 별개의 위상 오류다. 원본이나 자동 복구 도형은 저장하지 않았다.

- 존재 판정: visible:1 자체는 유지한다. 음성으로 바꾸지 않는다.
- 형상: 3건은 처리 미확정으로 별도 집계한다. 유효 도형만의 면적 집계를 공식 평가 대상 수로 주장하지 않는다.
- 자동 buffer(0), make_valid, 래스터 변환 등으로 정답을 임의 복구하지 않는다.
- 로컬 평가기의 기본 동작은 미확정 정답이 있으면 형상 점수 및 종합 점수 산출을 중단하는 것이다. 존재 점수 및 명시적인 진단용 결과는 분리해서 낼 수 있다. 구현·검증 범위는 [평가기 문서](evaluation.md)를 따른다.
- 제공된 공식 평가 코드 또는 운영 측 답변으로 처리 기준을 확인한 뒤 정책을 버전으로 고정하고, 변경 시 기존 실험 결과와 구분한다.

2026-09-07 [공개 대회 데이터 페이지](https://aifactory.space/ko/task/9305/data)를 조회했으나 접근 가능한 본문에서는 자기 교차 정답 처리 기준을 확인하지 못했다. 이는 해당 기준이 존재하지 않는다는 뜻이 아니다. 운영 측 문의는 보내지 않았다.

## 검증 상태

합성 테스트로 입력 순서 독립성, scene 비중복·전체 포함, 양쪽 클래스 유지, 불가능한 분할 거부, 기존 분할 덮어쓰기 방지, 파일 내용·이름 변경 탐지를 확인했다. 실제 데이터로 생성 후 --check 재검증을 수행한다. 고정 분할은 구현 완료이며 로컬 평가기도 구현했다. 공식 서버 동등성은 미검증이며 학습·모델 성능은 미구현/미측정 상태다.

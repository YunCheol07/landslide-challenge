# 대회 조건 — 사용자 제공 정보 기록

## 과제·평가
알려진 개소별로 각 날짜의 흔적 존재 여부와 경계를 예측한다.

- 입력: 창별 bands/<date>.npy (256×256×4 uint16, R/G/B/NIR), images/<date>.png, sites.json.
- 반사율 = 값 / 10000. 유효 화소 = Red>0 & NIR>0. 2022년 오프셋 재보정 금지.
- 사전 폴리곤은 위치 힌트. 라벨에 없는 개소-시점 및 ignore는 학습·평가 제외.
- 최종 점수 = 0.6 × 존재 macro-F1 + 0.4 × 형상 mIoU. 동점은 존재 점수 우선.
- 형상 평가: 보임 정답 중 면적 1,000m²(10px²) 이상. 연속 좌표 교차/합집합 면적 사용. 개소 내 시점 평균 후 개소 평균. 미예측은 IoU 0.
- Public 30%, Private 70%. 최종 순위는 Private 기준.

## 제출
- predict.ipynb와 assets/만 묶인다. 코드 모듈 등 추론 의존 파일도 이 범위에 포함해야 한다.
- AIF_INPUT_DIR에서 입력을 읽고 AIF_PREDICTION_PATH에 CSV를 쓴다. 경로 하드코딩 금지.
- CSV: location_id,date,site_id,polygons. 한 개소-날짜 한 행, 256px 좌표 MultiPolygon coordinates JSON. 빈 값/행 누락은 안 보임.
- ZIP ≤6GB, 설치 ≤10분, 추론 ≤60분. 설치 후 추론은 네트워크 차단.
- 서버: A10G 24GiB, CPU 4 vCPU, RAM 16GiB.
- 일반 팀당 1일 3회, 재제출 간격 30분. 디버그 팀당 1일 10회.
- 참여키는 AIF_API_KEY 환경변수 권장. 키를 Git 또는 노트북 출력에 남기지 않는다.

## 이용·출처 규칙
- 도용, 저작권 침해, 허위, 타 대회 입상작 등 부정행위는 수상 취소·상금 반환 대상.
- 제공 위성영상은 대회 참여 목적으로만 사용하며 외부 유포·제3자 공개/양도 및 목적 외 사용 금지.
- 사용자 제공 원문에는 고의/과실 복제·복사·이동 보유 시 운영자에게 즉시 공지하고 운영자 입회하에 파기한다는 조건이 있다. 따라서 기존 데이터에 대한 복사·이동 없이 읽기 참조만 한다. 해당 상황 발생 시 임의 삭제 대신 사용자에게 알려 운영 절차를 따른다.
- 외부 데이터 허용. 상업 이용·파생·재배포가 명확히 허용되어야 하고 모델 양도 조건을 확인한다. 상업 위성은 별도 권리 입증, 공공데이터는 상업 이용 가능 유형 확인.
- 동일 조건은 사전학습 가중치 및 그 학습 데이터가 최종 모델에 부과하는 제한에도 적용.
- 수상 시 학습 모델(가중치·파생 결과물 포함) 양도양수 계약. 학습 데이터셋은 양도·재판매 대상 아님.
- 외부 자산 출처와 라이선스는 코드 설명서에 기록. 준수 여부를 확인하지 않은 자산은 사용하지 않는다.
- 9/7 공지: LICENSE/NOTICE만 추가, 코드·가중치 변경 없음. 배포 안내에 따라 SAM3 또는 파생 가중치 제출 시 LICENSE 동봉.
- 상위팀은 검증 기간 내 지정 서식의 코드 설명서를 cs@aifactory.page로 제출해야 한다. 실제 발송은 사용자 지시 후 수행.
